# Task 3 — End-to-End Fraud Detection & Risk Analysis System

Standalone Streamlit fraud analytics portal.

## Included
- Transaction data-quality audit
- Fraud-rate and pattern EDA
- Numerical/categorical preprocessing
- Class-imbalance handling with class-weighted models
- Logistic Regression, Random Forest and Gradient Boosting
- Precision, Recall, F1, ROC-AUC and PR-AUC
- Configurable fraud-alert threshold
- False-positive and false-negative analysis
- Fraud probability and Low/Medium/High/Critical risk
- Investigation queue download
- Practical fraud-control recommendations

## Run
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```
